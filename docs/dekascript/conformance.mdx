# Runtime and application testing

The standalone historical conformance corpus is retired. Deka validates its
runtime with tests in the repository that owns the compiler and runtime code,
including execution, host operations, component events and packaging.

Use `deka test` for your application's DekaScript tests (`npx deka test` for an
npm installation). This command remains part of the product; retiring the corpus
does not retire application testing.

See [the native runtime preview](./native-runtime) for the migration boundary.
