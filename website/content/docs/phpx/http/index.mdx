The `http` module sends outbound network requests from PHPX. It exposes one-line helpers for common calls, a full request map for advanced cases, reusable clients with optional cookie jars, streaming request and response handles, and a WebSocket client.

Every network call returns a `Result` value. Runtime capability checks still apply: the host must be allowed by the application's `deka.json` network policy before a request can leave the sandbox.

## Imports

```phpx
import {
  http_get,
  http_post,
  http_request,
  http_client,
  http_stream_read,
  http_stream_close,
  http_req_stream_new,
  ws_connect,
} from 'http'
```

## Request Shapes

`http_request` accepts a map with these common fields:

- `method`: HTTP method such as `GET`, `POST`, `PUT`, or `DELETE`
- `url`: absolute `http://` or `https://` URL
- `headers`: map of request headers
- `body`: string request body
- `body_bytes`: byte-array request body
- `body_stream_handle`: handle from `http_req_stream_new`
- `timeout_ms`: per-request timeout
- `stream_response`: when true, returns a response with `stream_handle`
- `response_as_bytes`: when true, returns body bytes instead of a string
- `transport`: test or middleware callable with the same request/response contract

Response values are maps with `status`, `headers`, `version`, `final_url`, `body`, `body_bytes`, `streamed`, and `stream_handle`.

## Examples

```phpx
import { http_get, http_request } from 'http'
import { result_is_ok } from 'core/result'

$res = http_get('https://api.example.com/status', {
  'User-Agent': 'deka',
})

if (result_is_ok($res)) {
  echo $res->value->body
}

$created = http_request({
  method: 'POST',
  url: 'https://api.example.com/items',
  headers: { 'Content-Type': 'application/json' },
  body: '{"name":"demo"}',
  timeout_ms: 10000,
})
```

```phpx
import { http_client } from 'http'

$client_res = http_client({
  timeout_ms: 30000,
  max_redirects: 5,
  cookie_jar: true,
})

$client = $client_res->value
$login = $client->do({
  method: 'POST',
  url: 'https://api.example.com/login',
  headers: { 'Content-Type': 'application/json' },
  body: '{"user":"sami"}',
})

$me = $client->do({
  method: 'GET',
  url: 'https://api.example.com/me',
})

$client->close()
```

```phpx
import { http_request, http_stream_read, http_stream_close } from 'http'

$res = http_request({
  method: 'GET',
  url: 'https://example.com/export.ndjson',
  stream_response: true,
})

$response = $res->value
while (true) {
  $chunk = http_stream_read($response->stream_handle, 10000)
  if ($chunk['done']) {
    break
  }
  if (!$chunk['ok']) {
    break
  }
}
http_stream_close($response->stream_handle)
```
