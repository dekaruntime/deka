The `encoding` modules cover structured JSON and fixed-width binary values. JSON helpers live at `encoding/json`; binary packing and reading helpers live at `encoding/binary`.

Use the JSON module when a PHPX application needs PHP-compatible `json_encode`, `json_decode`, `json_validate`, or explicit `Result`-style decode errors. Use the binary module when building or parsing byte-oriented protocols with unsigned 16-bit and 32-bit integers.

## Imports

```phpx
import { json_encode, json_decode_result, json_validate } from 'encoding/json'
import { u16_be, read_u32_le, append_u16_be } from 'encoding/binary'
```

## JSON

`json_decode_result` is the safer form for application code because callers can handle invalid JSON without relying on global JSON error state.

```phpx
import { json_decode_result } from 'encoding/json'
import { result_is_ok } from 'core/result'

$decoded = json_decode_result('{"ok":true}', true)
if (result_is_ok($decoded)) {
  echo $decoded->value['ok']
}
```

## Binary Values

The binary helpers return bytes for writers and structured maps for readers. Reader maps contain `ok`, `value`, and `next` on success, or `ok: false` with an error string on short reads.

```phpx
import { u16_be, append_u32_le, read_u16_be } from 'encoding/binary'

$packet = append_u32_le(u16_be(7), 1024)
$field = read_u16_be($packet, 0)
```
