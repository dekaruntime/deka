The `payments` module is the shared provider layer for commerce applications. It normalizes Stripe, Square, and PayPal operations behind common account, charge, refund, event, and account-status shapes.

The module also owns platform-fee math and provider security helpers: OAuth state, return URL validation, webhook HMAC verification, refund authorization, refund audit logging, and encrypted provider-token storage.

## Imports

```phpx
import {
  platform_fee_cents,
  new_charge,
  verify_hmac_sha256,
```

## Common Flow

```phpx
import {
  platform_fee_cents,
  stripe_connect_url,
  stripe_create_charge,
} from 'payments'
import { result_is_ok } from 'core/result'

$connect = stripe_connect_url(
  'https://store.example.com/payments/stripe/callback',
  'shop_123',
  'session_jti_456',
  $http_transport
)

if (result_is_ok($connect)) {
  echo $connect->value->url
}

$fee = platform_fee_cents(10000, 'standard')
$charge = stripe_create_charge(
  $account,
  10000,
  'usd',
  $fee,
  'checkout_abc123',
  $http_transport
)
```

## Fee Math

<Function name="platform_fee_cents">
  <Description>Calculate Tana's platform fee in cents for a charge amount and merchant tier. The fee is capped by tier and returns zero for non-positive amounts.</Description>
  <Parameter name="$amount_cents" type="int" required="true" typeLink="/docs/php/types/int">
    Charge amount in the smallest currency unit.
  </Parameter>
  <Parameter name="$tier" type="string" required="true" typeLink="/docs/php/types/string">
    Merchant tier: `free`, `standard`, `premium`, or `enterprise`.
  </Parameter>
  <ReturnType type="int" typeLink="/docs/php/types/int" />
</Function>

Tier schedule:

- `free`: 1.0%, capped at 200 cents
- `standard`: 0.5%, capped at 100 cents
- `premium`: 0.25%, capped at 50 cents
- `enterprise`: no platform fee

## Provider Functions

Stripe exports `stripe_connect_url`, `stripe_handle_callback`, `stripe_create_charge`, `stripe_refund`, `stripe_webhook_verify`, `stripe_account_status`, and `stripe_disconnect`.

Square exports `square_connect_url`, `square_handle_callback`, `square_create_charge`, `square_refund`, `square_webhook_verify`, `square_account_status`, `square_refresh_token`, and `square_disconnect`.

PayPal exports `paypal_connect_url`, `paypal_handle_callback`, `paypal_create_charge`, `paypal_refund`, `paypal_webhook_verify`, and `paypal_account_status`.
