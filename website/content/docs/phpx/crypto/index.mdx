The `crypto` module wraps the runtime crypto bridge and PHP hashing primitives behind PHPX-friendly helpers. It is intended for application-level tokens, identifiers, signatures, and authenticated encryption.

Functions that can fail return `Result` values from `core/result`. Check the result before using the value, especially for random byte generation and AES operations.

## Imports

```phpx
import {
  random_bytes_result,
  random_hex,
  sha256_hex,
  hmac_sha256_hex,
  hmac_sha256_bytes,
  secure_compare,
  uuid_v4,
  aes_256_gcm_encrypt,
  aes_256_gcm_decrypt,
} from 'crypto'
```

## Random Values

Use `random_bytes_result` when you need raw bytes and `random_hex` when a printable token is enough. Both validate that the requested length is greater than zero and return `Result<bytes|string, string>`.

```phpx
import { random_hex, uuid_v4 } from 'crypto'
import { result_is_ok } from 'core/result'

$token = random_hex(32)
if (result_is_ok($token)) {
  echo $token->value
}

$id = uuid_v4()
```

## Hashing And MACs

`sha256_hex` hashes a value after converting it to a string. `hmac_sha256_hex` and `hmac_sha256_bytes` sign stringified input with a secret key. Use `secure_compare` when comparing a provided signature or token to an expected value.

```phpx
import { hmac_sha256_hex, secure_compare } from 'crypto'

$expected = hmac_sha256_hex($body, $secret)
if (!secure_compare($expected, $provided)) {
  return { ok: false, error: 'invalid signature' }
}
```

## AES-256-GCM

`aes_256_gcm_encrypt` and `aes_256_gcm_decrypt` use a 32-byte key and a 12-byte nonce. The nonce must be unique for each encryption with the same key. Ciphertext includes the 16-byte authentication tag appended to the encrypted bytes.

```phpx
import { random_bytes_result, aes_256_gcm_encrypt, aes_256_gcm_decrypt } from 'crypto'
import { result_is_ok } from 'core/result'

$key = random_bytes_result(32)
$nonce = random_bytes_result(12)

if (result_is_ok($key) && result_is_ok($nonce)) {
  $sealed = aes_256_gcm_encrypt($key->value, $nonce->value, 'secret payload', 'v1')
  if (result_is_ok($sealed)) {
    $opened = aes_256_gcm_decrypt($key->value, $nonce->value, $sealed->value, 'v1')
  }
}
```
