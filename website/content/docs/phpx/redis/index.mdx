The `redis` module exposes direct Redis operations through the runtime bridge. Use it for short-lived cache entries, counters, OAuth state, rate limits, and queue-like list data.

All functions take an explicit Redis handle after `connect`. The runtime returns bridge-shaped values, so check the returned `ok` or `Result` shape used by the caller before trusting values.

## Imports

```phpx
import {
  connect,
  get,
  set,
  del,
  exists,
  expire,
  ttl,
  incr,
  decr,
  hget,
  hset,
  hgetall,
  hdel,
  lpush,
  rpush,
  lpop,
  rpop,
  lrange,
  llen,
  ltrim,
  sadd,
  smembers,
  srem,
  sismember,
  keys,
  flush,
  close,
} from 'redis'
```

## Example

```phpx
import { connect, set, get, incr, expire, close } from 'redis'

$conn = connect('redis://localhost:6379')
$handle = $conn['handle']

set($handle, 'session:user-1', 'active', 600)
$session = get($handle, 'session:user-1')

$count = incr($handle, 'rate:user-1')
expire($handle, 'rate:user-1', 60)

close($handle)
```

## Hash, List, Set, and Admin Helpers

Hash helpers: `hget`, `hset`, `hgetall`, and `hdel`.

List helpers: `lpush`, `rpush`, `lpop`, `rpop`, `lrange`, `llen`, and `ltrim`.

Set helpers: `sadd`, `smembers`, `srem`, and `sismember`.

Administrative helpers: `keys`, `flush`, and `close`.

Use `keys` and `flush` carefully in production code; they are broad operations and should normally be reserved for maintenance tooling or isolated test databases.
